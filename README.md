# consultation-service

Бэкенд-сервис записи студентов на консультации к преподавателям — часть
командного проекта «Система записи студентов на консультации преподавателей».

Используется как практическая часть лабораторной работы по инструментальным
средствам управления версиями и составления проектной документации:
история коммитов в репозитории показывает работу с Git (ветки, слияния,
разрешение конфликтов), а код сопровождён doc-комментариями в стиле Go,
которые можно посмотреть через `go doc`/`pkgsite` — аналог Doxygen для
Go-проектов.

## Стек

Go, gorilla/mux, GORM, PostgreSQL

## Структура проекта

```
cmd/server          — точка входа, запуск HTTP-сервера
internal/config      — конфигурация из переменных окружения
internal/models      — доменные сущности (User, ConsultationSlot, Booking, ...)
internal/repository   — слой доступа к данным (GORM)
internal/handlers      — HTTP-обработчики и маршруты
```

## Возможности

- Преподаватель создаёт слоты консультаций по дисциплине на определённое время;
  слоты одного преподавателя не могут пересекаться по времени.
- Студент записывается на слот; если мест не осталось — запись отклоняется.
  Проверка вместимости и запись выполняются в одной транзакции с блокировкой
  строки, чтобы конкурентные запросы не переполнили слот.
- Студент отменяет свою запись и смотрит список своих записей.

## Запуск

```
go mod tidy
go build ./...

set HTTP_ADDR=:8080
set DSN=host=localhost user=postgres password=postgres dbname=consultations port=5432 sslmode=disable

go run ./cmd/server
```

## API

| Метод  | Путь                       | Описание                    |
|--------|-----------------------------|-------------------------------|
| POST   | /slots                      | создать слот консультации    |
| GET    | /teachers/{id}/slots        | список слотов преподавателя  |
| POST   | /bookings                   | записаться на консультацию   |
| DELETE | /bookings/{id}?student_id=  | отменить запись               |
| GET    | /students/{id}/bookings     | список записей студента      |
